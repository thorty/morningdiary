# 07 — Browse Personal Journal

**What to build:** A user can open the Personal Journal and review every retained Daily Snapshot in newest-first order, including snapshots that have a Coach Summary and those that do not.

**Blocked by:** 05 — Complete Daily Snapshot without an LLM.

**Status:** ready-for-agent

- [ ] A public backend operation returns all retained Daily Snapshots ordered newest first.
- [ ] The German Personal Journal view renders each snapshot’s recorded date, mood rating when supplied, responses, and available Coach Summary or absence note.
- [ ] The view does not expose editing or deletion of completed Daily Snapshots.
- [ ] API and UI tests verify newest-first ordering and rendering snapshots with and without Coach Summaries.
