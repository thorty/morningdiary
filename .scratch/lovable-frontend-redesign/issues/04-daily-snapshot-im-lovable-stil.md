# 04 — Daily Snapshot im Lovable-Stil

**What to build:** Nach Abschluss sieht der Journal Owner den unveränderlichen Daily Snapshot als eigenständige, visuell wertige Karte mit den tatsächlich vom Backend gelieferten Daten.

**Blocked by:** 03 — Fokussierter Morning Check-in.

**Status:** ready-for-agent

- [ ] Während des Abschlusses wird ein verständlicher Verarbeitungszustand angezeigt.
- [ ] Der fertige Daily Snapshot zeigt Datum, vorhandene Stimmung und alle sechs Check-in Responses in deutscher Routine Language.
- [ ] Eine vorhandene Coach Summary wird gut lesbar und visuell hervorgehoben angezeigt.
- [ ] Ohne Coach Summary bleibt der Daily Snapshot vollständig und zeigt einen ruhigen deutschen Fallback statt technischer Details.
- [ ] Ein Blank Check-in wird korrekt ohne erfundene Stimmung oder Coach Summary dargestellt.
- [ ] Der Daily Snapshot bietet keine Bearbeitungs-, Lösch- oder LLM-Retry-Aktion.
- [ ] Die Darstellung funktioniert responsiv und verwendet keine Lovable-spezifische strukturierte Coach-Summary- oder Antwortform.
- [ ] UI-Tests prüfen Daily Snapshots mit und ohne Stimmung, Antworten und Coach Summary.
